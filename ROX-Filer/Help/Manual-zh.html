什么是 Rox-Filer2

Rox-Filer2 是 ROX-Filer 的延续，已升级到 GTK3，并增加了现代界面、原生 SMB 支持、驱动器图标，以及在 X11 和 Wayland 上都能运行的桌面模式。

它在一个进程中只做一件事：管理文件，并在您需要时管理桌面。没有后台守护进程，没有虚拟文件系统层，也不依赖任何桌面环境。您看到的一切都是普通的 POSIX 路径。

经典界面与现代界面

Rox-Filer2 提供两种界面风格，二者共用相同的文件、MIME、挂载、回收站和桌面后端。

  • 经典 ROX 保留 ROX-Filer 传统的布局和工具栏。若您从 ROX-Filer 迁移而来，一切位置照旧。
  • 现代 增加了菜单栏、导航栏、标签页，以及包含「位置」「设备」「网络」的侧边栏。

在选项 > 界面中选择长期使用的风格。更改会在重启 Rox-Filer2 之后打开的窗口中生效。

若只想临时试用某种风格而不改动已保存的偏好，请以 rox --classic 或 rox --modern 启动。

文件管理器窗口

双击可打开目录。单击为选中；在空白处按住左键拖动可进行框选。

  • 右键打开指针下方项目的上下文菜单；在空白处则是整个窗口的菜单。
  • 中键在新窗口中打开目录。
  • Backspace 返回上一级；Ctrl+L 聚焦路径输入框。
  • 在现代界面中，Ctrl+T 新建标签页，Ctrl+W 关闭。每个标签页各自保留路径与历史记录。

使用视图切换器在图标视图与详细列表视图之间切换，并用滑块调整图标大小。

ROX 桌面

使用 rox --desktop 启动桌面。同一时间只运行一个实例。它会绘制壁纸、显示桌面目录中的图标，并可显示驱动器图标。

  • 壁纸：rox --desktop-wallpaper，或在桌面上右键。模式包括填充、适应、拉伸、居中和平铺。
  • 应用程序：rox --desktop-apps 管理桌面上的启动器。
  • 驱动器图标：rox --desktop-drive-icon-layout 用于排列。
  • 首选项：rox --desktop-preferences。

在 X11 上，桌面使用带桌面类型提示的普通窗口。在 Wayland 上使用 Layer Shell 的背景层，这需要安装 gtk-layer-shell，并且合成器需公开 zwlr_layer_shell_v1，例如 Labwc。可用 rox-x11 --desktop 或 rox-wayland --desktop 强制指定后端。

若还希望设置 X11 根窗口背景，使伪透明终端和 conky 看到同一张图像，请安装 feh 或 xwallpaper。

驱动器与挂载

本地和可移动驱动器显示在现代界面侧边栏的设备下，也可显示为桌面图标。单击驱动器即可挂载并打开；通过上下文菜单卸载。

驱动器信息来自 lsblk、/proc/mounts 和 sysfs，因此无需任何后台服务。以普通用户身份挂载需要 udisksctl，或在 fstab 中有允许挂载的条目。

拔出可移动介质前请务必先卸载。关闭窗口后 Rox-Filer2 不会再向设备写入，但内核可能仍保留尚未写出的数据。

磁盘映像 (ISO、IMG、SFS、SquashFS)

右键单击映像文件并选择挂载映像。Rox-Filer2 会将其关联到回环设备并以只读方式挂载，然后像打开任何其他目录一样打开结果。支持的扩展名为 .iso、.img、.sfs、.squashfs、.sqfs 和 .sqsh。

挂载后，同一菜单会提供打开已挂载映像和卸载映像。挂载点位于 /media/rox-filer2-images/ 下，每个映像一个目录。

  • 始终只读。回环设备、块设备和挂载三者都设为只读，因此映像绝不会被意外修改。
  • 以 root 运行时（Puppy 和 Essora 的常规方式）直接使用 losetup 和 mount。以普通用户运行时使用 udisksctl，需要事先安装。
  • 原始 .img 文件可能包含分区表。发现多个分区时，Rox-Filer2 会询问挂载哪一个，并显示每个分区的真实编号、文件系统、大小和卷标。ISO 和 SquashFS 映像始终整体挂载，即使混合 ISO 暴露了分区表也是如此。
  • 不使用 GVfs。映像成为普通的本地挂载点，因此复制、拖放、MIME 处理和自定义操作的行为与其他目录完全一致。

挂载在后台进行：准备回环设备和扫描分区期间会显示一个带有旋转指示器的小窗口，文件管理器保持响应。

删除或移动映像文件之前请先卸载。如果挂载在 Rox-Filer2 不知情的情况下消失，菜单项会重新提供挂载映像。

SMB 与 Windows 共享

打开转到 > 连接到 SMB 共享，或现代界面侧边栏中的浏览网络。输入服务器，若知道共享名也一并输入；列表按钮会向服务器询问它提供哪些共享。

Rox-Filer2 通过 mount.cifs 将共享挂载为普通的本地挂载点，而不是用虚拟文件系统呈现。因此复制、拖放、MIME 处理、回收站和自定义操作的行为与本地文件完全一致。

  • 必须安装 cifs-utils。
  • 挂载需要 root 权限。以普通用户运行时，Rox-Filer2 会尝试 sudo -n；为 mount.cifs 配置免密规则实际上等同于授予 root，请在了解后果的前提下配置，或自行手动挂载。
  • 密码绝不会写入配置文件。它通过一个仅您可读的临时凭据文件传递，mount.cifs 返回后立即删除。只有服务器、共享、用户和域会被记住。

回收站

通过菜单删除会将项目移入 XDG 回收站，因此可以恢复。请在回收站目录的上下文菜单中执行恢复。

回收站仅在与回收站目录相同的文件系统内有效。删除位于其他分区或可移动设备上的文件可能无法恢复，出现这种情况时 Rox-Filer2 会提示您。

文件类型与「打开方式」

文件类型来自共享 MIME 数据库，以及文件自身设置的扩展属性。上下文菜单的打开方式中列出为该类型注册的应用程序。

可通过项目的设置图标和设置运行动作指定固定的处理程序或自定义图标。它们保存在您自己的配置中，绝不会修改系统数据库。

自定义操作与模板

自定义操作会把您自己的命令加入上下文菜单，并将选中的路径作为参数传入。它们是普通的 desktop 条目，可以在不同机器之间复制。

模板让您可以从上下文菜单创建指定类型的新空文件。把文件放进应用程序目录下的 Templates 目录，即可添加自己的模板。

搜索、书签与成对窗口

  • 搜索：rox-find 可按名称、大小、类型和内容搜索，并把结果交回文件管理器。
  • 书签：让常用目录一击即达；在现代界面中它们也出现在「位置」下。
  • 成对窗口：rox --pair 并排打开两个窗口以便在目录之间复制，rox --pair-realign 可重新对齐。

选项与配置文件

可从编辑菜单、桌面菜单或使用 rox --config-rox 打开选项。

您的设置位于 XDG 配置目录，通常是 ~/.config/rox.sourceforge.net/ROX-Filer/。这些文件是 XML、INI 和纯文本，可以备份、编辑或在机器之间复制。删除某个文件即可将该组设置恢复为默认值。

命令行

  • rox — 自动选择 X11 或 Wayland 后端。
  • rox-x11、rox-wayland — 强制指定后端。
  • rox 目录 — 打开目录。
  • rox -d 目录 — 即使它是应用程序目录，也作为目录打开。
  • rox -D 目录 — 关闭该目录及其子目录。
  • rox --classic、rox --modern — 临时覆盖界面风格。
  • rox --desktop — 启动桌面；--desktop-refresh 刷新正在运行的桌面。
  • rox --help — 完整列表。

诊断

日志默认关闭。使用 rox --debug 启动以写入技术日志，--log-file=文件 指定位置，--log-level=级别 可取 error、warning、info、debug 或 trace。rox --clear-logs 会删除 Rox-Filer2 自动管理的日志。

报告问题时请附上该日志。它记录了选用了哪个桌面后端、当前生效的界面风格，以及 SMB 挂载或驱动器扫描失败的原因。
