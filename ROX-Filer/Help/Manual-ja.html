Rox-Filer2 とは

Rox-Filer2 は ROX-Filer の後継であり、GTK3 に更新したうえで、モダンなインターフェース、ネイティブな SMB 対応、ドライブアイコン、そして X11 と Wayland の両方で動作するデスクトップモードを追加しています。

ひとつのプロセスでひとつの仕事だけを行います。ファイルを管理し、必要であればデスクトップも管理します。常駐デーモンも、仮想ファイルシステム層も、デスクトップ環境への依存もありません。表示されるものはすべて通常の POSIX パスです。

クラシックとモダンのインターフェース

Rox-Filer2 には 2 つのインターフェーススタイルがあり、ファイル、MIME、マウント、ごみ箱、デスクトップの各基盤を共有しています。

  • クラシック ROX は従来の ROX-Filer のレイアウトとツールバーをそのまま保ちます。ROX-Filer からの移行であれば、配置は変わりません。
  • モダン はメニューバー、ナビゲーション行、タブ、そして「場所」「デバイス」「ネットワーク」を含むサイドバーを追加します。

常用するスタイルは オプション > インターフェース で選びます。変更は Rox-Filer2 を再起動したあとに開くウィンドウに適用されます。

保存された設定を変えずに一度だけ試すには、rox --classic または rox --modern で起動してください。

ファイラーウィンドウ

ディレクトリはダブルクリックで開きます。シングルクリックは選択で、空白部分を左ボタンでドラッグすると矩形選択になります。

  • 右ボタンはポインター下の項目のコンテキストメニューを開きます。空白部分ではウィンドウ全体のメニューになります。
  • 中ボタンはディレクトリを新しいウィンドウで開きます。
  • Backspace で 1 階層上に移動し、Ctrl+L でパス入力欄にフォーカスします。
  • モダンでは Ctrl+T でタブを開き、Ctrl+W で閉じます。各タブはそれぞれのパスと履歴を保持します。

アイコン表示と詳細表示はビュー切り替えで変更でき、アイコンの大きさはスライダーで調整します。

ROX デスクトップ

デスクトップは rox --desktop で起動します。同時に動作するのは 1 つだけです。壁紙を描画し、デスクトップディレクトリのアイコンを表示し、ドライブアイコンを表示することもできます。

  • 壁紙: rox --desktop-wallpaper、またはデスクトップの右クリック。モードは塗りつぶし、全体表示、引き伸ばし、中央、タイルです。
  • アプリケーション: rox --desktop-apps がデスクトップのランチャーを管理します。
  • ドライブアイコン: rox --desktop-drive-icon-layout で整列します。
  • 設定: rox --desktop-preferences。

X11 ではデスクトップ種別のヒントを付けた通常のウィンドウを使います。Wayland では Layer Shell の背景レイヤーを使うため、gtk-layer-shell がインストールされ、Labwc のように zwlr_layer_shell_v1 を公開するコンポジターが必要です。rox-x11 --desktop または rox-wayland --desktop でバックエンドを固定できます。

擬似透過のターミナルや conky に同じ画像を見せるため X11 のルートウィンドウの背景も設定したい場合は、feh または xwallpaper をインストールしてください。

ドライブとマウント

ローカルおよびリムーバブルのドライブは、モダンのサイドバーのデバイスに表示され、必要に応じてデスクトップアイコンにもなります。ドライブをクリックするとマウントして開き、アンマウントはコンテキストメニューから行います。

ドライブの情報は lsblk、/proc/mounts、sysfs から取得するため、常駐サービスは不要です。一般ユーザーがマウントするには udisksctl か、それを許可する fstab エントリーが必要です。

リムーバブルメディアは取り外す前に必ずアンマウントしてください。Rox-Filer2 はウィンドウを閉じたあとにデバイスへ書き込むことはありませんが、カーネルが未書き込みのデータを保持している場合があります。

ディスクイメージ (ISO, IMG, SFS, SquashFS)

イメージファイルを右クリックしてイメージをマウントを選びます。Rox-Filer2 はループデバイスに割り当てて読み取り専用でマウントし、その結果を通常のディレクトリと同じように開きます。対応する拡張子は .iso、.img、.sfs、.squashfs、.sqfs、.sqsh です。

マウント後は同じメニューにマウント済みイメージを開くとイメージをアンマウントが現れます。マウント先は /media/rox-filer2-images/ の下で、イメージごとに 1 つのディレクトリです。

  • 常に読み取り専用です。ループデバイス、ブロックデバイス、マウントのいずれも読み取り専用に設定されるため、イメージを誤って変更することはありません。
  • root の場合（Puppy と Essora の通常の形態）は losetup と mount を直接使います。一般ユーザーの場合は udisksctl を使うため、これがインストールされている必要があります。
  • 生の .img ファイルにはパーティションテーブルが含まれることがあります。複数見つかった場合、Rox-Filer2 はどれをマウントするか尋ね、各パーティションの実際の番号、ファイルシステム、サイズ、ラベルを表示します。ISO と SquashFS のイメージは、ハイブリッド ISO がパーティションテーブルを持つ場合でも常に全体をマウントします。
  • GVfs は使いません。イメージは通常のローカルマウントになるため、コピー、ドラッグ＆ドロップ、MIME 処理、カスタムアクションはほかのディレクトリとまったく同じように動作します。

マウントはバックグラウンドで実行されます。ループデバイスの準備とパーティションの走査の間は小さなウィンドウにスピナーが表示され、ファイラーは操作可能なままです。

イメージファイルを削除または移動する前にアンマウントしてください。Rox-Filer2 の知らないうちにマウントが消えた場合、メニュー項目は再びイメージをマウントを表示します。

SMB と Windows 共有

移動 > SMB 共有に接続、またはモダンのサイドバーのネットワークを参照を開きます。サーバー名と、分かっていれば共有名を入力します。一覧ボタンはサーバーに提供している共有を問い合わせます。

Rox-Filer2 は仮想ファイルシステムで見せるのではなく、mount.cifs を使って通常のローカルマウントとして共有をマウントします。そのためコピー、ドラッグ＆ドロップ、MIME 処理、ごみ箱、カスタムアクションはローカルファイルとまったく同じように動作します。

  • cifs-utils がインストールされている必要があります。
  • マウントには root 権限が必要です。一般ユーザーの場合 Rox-Filer2 は sudo -n を試みます。mount.cifs に対するパスワード不要の許可は事実上 root を与えることと同じですので、理解したうえで設定するか、ご自身でマウントしてください。
  • パスワードが設定ファイルに書かれることはありません。本人だけが読める一時的な資格情報ファイルを経由し、mount.cifs が終了した時点で削除されます。記憶されるのはサーバー、共有、ユーザー、ドメインだけです。

ごみ箱

メニューからの削除は項目を XDG のごみ箱へ移動するため、あとから復元できます。復元はごみ箱ディレクトリのコンテキストメニューから行います。

ごみ箱はごみ箱ディレクトリと同じファイルシステム内でのみ機能します。別のパーティションやリムーバブルデバイス上のファイルの削除は復元できないことがあり、その場合 Rox-Filer2 が警告します。

ファイル種別と「アプリケーションで開く」

ファイル種別は共有 MIME データベースと、ファイル自体に設定された拡張属性から判定されます。コンテキストメニューのアプリケーションで開くに、その種別に登録されたアプリケーションが並びます。

既定の処理プログラムや独自のアイコンは、項目のアイコンを設定とアクションを設定から指定します。これらはご自身の設定に保存され、システムのデータベースを変更することはありません。

カスタムアクションとテンプレート

カスタムアクションは独自のコマンドをコンテキストメニューに追加し、選択されたパスを引数として受け取ります。通常のデスクトップエントリーなので、別のマシンへコピーできます。

テンプレートを使うと、指定した種類の空ファイルをコンテキストメニューから作成できます。アプリケーションディレクトリの Templates ディレクトリにファイルを置けば、独自のテンプレートを追加できます。

検索・ブックマーク・ペアウィンドウ

  • 検索: rox-find は名前、サイズ、種別、内容で検索し、結果をファイラーへ返します。
  • ブックマーク: よく使うディレクトリをワンクリックで開けるようにします。モダンでは「場所」にも表示されます。
  • ペアウィンドウ: rox --pair はディレクトリ間のコピー用に 2 つのウィンドウを並べて開き、rox --pair-realign で並べ直せます。

オプションと設定ファイル

オプションは編集メニュー、デスクトップメニュー、または rox --config-rox から開けます。

設定は XDG の設定ディレクトリ、通常は ~/.config/rox.sourceforge.net/ROX-Filer/ に置かれます。ファイルは XML、INI、プレーンテキストなので、バックアップ、編集、別マシンへのコピーができます。ファイルを削除すると、その設定群が既定値に戻ります。

コマンドライン

  • rox — X11 か Wayland のバックエンドを自動選択します。
  • rox-x11、rox-wayland — バックエンドを固定します。
  • rox DIR — ディレクトリを開きます。
  • rox -d DIR — アプリケーションディレクトリであってもディレクトリとして開きます。
  • rox -D DIR — そのディレクトリとサブディレクトリを閉じます。
  • rox --classic、rox --modern — インターフェースの一時的な切り替えです。
  • rox --desktop — デスクトップを起動します。--desktop-refresh は動作中のものを更新します。
  • rox --help — 全一覧です。

診断

ログ出力は既定で無効です。技術ログを書き出すには rox --debug で起動し、出力先は --log-file=ファイル、詳細度は --log-level=レベル に error、warning、info、debug、trace のいずれかを指定します。rox --clear-logs は Rox-Filer2 が自動管理しているログを削除します。

問題を報告する際はこのログを添えてください。どのデスクトップバックエンドが選ばれたか、どのインターフェーススタイルが有効か、SMB マウントやドライブ走査がなぜ失敗したかが記録されています。

問題の報告

不具合や提案はプロジェクトページ github.com/josejp2424/ROX-Filer-gtk3 へお寄せください。

ご使用のバージョン（ヘルプ > Rox-Filer2 についてを参照）、X11 と Wayland のどちらか、インターフェースのスタイル、そして問題を再現する正確な手順をお知らせください。
